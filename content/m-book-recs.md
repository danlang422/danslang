{% book "The Lilac People", "Milo Todd", "9781640097032", "https://www.goodreads.com/book/show/217045791-the-lilac-people" %}
This is that book that we randomly stumbled upon in the library, and that I almost ignored, but I'm *so* glad I didn't! While this is fiction, it is *steeped* 🫖 in history. Interestingly, I had just learned about Magnus Hirschfeld and the Institute for Sexual Science in a course on LGBTQ+ history when we found this book, and both are a big part of this story. The author takes some liberties with the timeline of certain events, and the main protagonist is not based on a specific person, but it's a beautiful, if somewhat tragic, tale (probably obviously, given the setting). It's beautifully written, and I learned a lot from it, as well. 
{% endbook %}
